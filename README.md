# 🌐 TPSIT 5ª — Linguaggi di Interscambio Dati & Markup: JSON, Markdown e XML

Percorso didattico interattivo di **135 minuti** (3 lezioni da 45 minuti) per le classi quinte degli Istituti Tecnici Industriali (Indirizzo Informatica e Telecomunicazioni - TPSIT).

🚀 **Web App Interattiva Live (GitHub Pages)**: [https://amarte81.github.io/tpsit-5-json-markdown-xml/](https://amarte81.github.io/tpsit-5-json-markdown-xml/)

## 📦 Contenuto del Repository

* **[`index.html`](./index.html)** — **Web App Interattiva (Single Page)** progettata per PC (16:9) e Smartphone (9:16), con modalità Alta Leggibilità (DSA/PDP), spiegazioni teoriche discorsive, 6 casi studio reali, 6 mini-test interattivi lungo lo scorrimento, sandbox live (JSON ↔ Classe Java e Markdown Live), 3 sezioni di Ripasso Denso e Sfida Finale sui 3 Casi Reali Simulati.
* **[`scheda_operativa_studenti.md`](./scheda_operativa_studenti.md)** — Scheda operativa ad alta densità informativa e checklist di ispezione per gli studenti.
* **[`piano_lezioni_docente.md`](./piano_lezioni_docente.md)** — Progettazione didattica dettagliata delle 3 lezioni da 45 minuti per il docente.
* **[`GUIDA_TECNICA_DOCENTE.md`](./GUIDA_TECNICA_DOCENTE.md)** — Manuale operativo per il docente: requisiti, avvio, configurazione Google Workspace e soluzioni complete di tutti gli esercizi.
* **[`google_workspace_script.gs`](./google_workspace_script.gs)** — Script Google Apps Script per raccogliere automaticamente le consegne su Google Sheets e calcolare in tempo reale il raggiungimento del criterio di successo (>= 90%).
* **[`esercizi-java-json/`](./esercizi-java-json/)** — **Percorso di esercizi JSON in Java con Gson**: esempio commentato (brano Spotify), esercizio guidato base (serie TV), esercizio guidato completo (watchlist su file: liste, `Map`, `TypeToken`, tree model, errori) ed esercizio con **socket TCP** (quiz multigiocatore stile Kahoot). Gson incluso in `lib/`, soluzioni per il docente in `soluzioni/`.
* **[`esercizi-java-markdown/`](./esercizi-java-markdown/)** — **Percorso di esercizi Markdown in Java con CommonMark**: esempio commentato (annuncio Discord), esercizio guidato base (scheda videogioco), esercizio guidato completo (portale torneo esports su file: estensioni GFM, YAML front matter, TOC automatico, `AttributeProvider`, costruzione AST → `MarkdownRenderer`, sicurezza XSS) ed esercizio con **socket TCP** (chatroom stile Discord con anteprima HTML live ed esportazione). Librerie `commonmark-java` incluse in `lib/`, soluzioni per il docente in `soluzioni/`.
