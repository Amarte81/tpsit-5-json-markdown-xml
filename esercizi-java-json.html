📖 00 — Esempio Commentato: "Il brano del momento" (Spotify)

ESEMPIO GUIDA • 20 MIN

Quando apri un brano su Spotify, l'app riceve dal server una stringa di testo JSON e la trasforma in un oggetto per mostrarti titolo, artista e durata. Questo esempio mostra l'intero ciclo: oggetto Java → JSON compatto → JSON indentato → deserializzazione → uso dei dati → gestione di chiavi mancanti o extra.

cd 00-esempio-spotify && java -cp ../lib/gson-2.11.0.jar EsempioBrano.java
⬇️ Scarica EsempioBrano.java 👁️ Apri su GitHub
📏 Le 4 regole d'oro della classe modello (POJO):
1) Il nome del campo Java diventa la chiave JSON (maiuscole/minuscole contano!).
2) I campi possono essere private: Gson accede comunque via reflection.
3) Inserisci sempre un costruttore vuoto per fromJson.
4) I metodi (es. getDurataFormattata()) servono a te, non finiscono nel JSON.
💻 Codice completo e commentato: EsempioBrano.java 
import com.google.gson.Gson;          // il "traduttore" Java <-> JSON
import com.google.gson.GsonBuilder;   // la "fabbrica" per creare un Gson configurato

public class EsempioBrano {
    public static void main(String[] args) {
        // PASSO 1 - Creo un normale oggetto Java
        Brano brano = new Brano("Tuta gold", "Mahmood", 188, 2024, false, 91.5);
        System.out.println("1) Oggetto Java: " + brano);

        // PASSO 2 & 3 - SERIALIZZAZIONE: oggetto Java -> stringa JSON compatta
        Gson gson = new Gson();
        String json = gson.toJson(brano);
        System.out.println("\n2) JSON compatto (viaggia in rete):\n   " + json);

        // PASSO 4 - Pretty printing con GsonBuilder (leggibile per gli umani)
        Gson gsonLeggibile = new GsonBuilder().setPrettyPrinting().create();
        System.out.println("\n3) JSON indentato:\n" + gsonLeggibile.toJson(brano));

        // PASSO 5 - DESERIALIZZAZIONE: stringa JSON -> oggetto Java
        String jsonRicevuto = """
                {
                  "titolo": "30\u00b0C",
                  "artista": "ANNA",
                  "durataSecondi": 147,
                  "annoUscita": 2024,
                  "esplicito": true,
                  "popolarita": 89.0
                }
                """;
        Brano ricevuto = gson.fromJson(jsonRicevuto, Brano.class);
        System.out.println("\n4) Oggetto ricostruito: " + ricevuto);

        // PASSO 6 - Ora e' un normale oggetto Java: uso getter, metodi, if...
        System.out.println("   Durata: " + ricevuto.getDurataFormattata()
                + " | Esplicito? " + (ricevuto.isEsplicito() ? "si' [E]" : "no"));

        // PASSO 7 - Chiavi extra ignorate ("genere"), chiavi mancanti -> default (0/false/null)
        String jsonIncompleto = "{\"titolo\":\"Espresso\",\"artista\":\"Sabrina Carpenter\",\"genere\":\"pop\"}";
        Brano parziale = gson.fromJson(jsonIncompleto, Brano.class);
        System.out.println("\n6) JSON incompleto: " + parziale);
    }
}

class Brano {
    private String titolo;
    private String artista;
    private int durataSecondi;
    private int annoUscita;
    private boolean esplicito;
    private double popolarita;

    public Brano() {} // Costruttore vuoto usato da Gson

    public Brano(String titolo, String artista, int durataSecondi,
                 int annoUscita, boolean esplicito, double popolarita) {
        this.titolo = titolo; this.artista = artista;
        this.durataSecondi = durataSecondi; this.annoUscita = annoUscita;
        this.esplicito = esplicito; this.popolarita = popolarita;
    }

    public String getDurataFormattata() {
        return String.format("%d:%02d", durataSecondi / 60, durataSecondi % 60);
    }
    public String getTitolo() { return titolo; }
    public boolean isEsplicito() { return esplicito; }
    public double getPopolarita() { return popolarita; }

    @Override
    public String toString() {
        return "Brano[" + titolo + " - " + artista + ", " + getDurataFormattata() + "]";
    }
}
🖥️ Output atteso in console (clicca per aprire) 
1) Oggetto Java (stampato con toString):
   Brano[Tuta gold - Mahmood, 3:08, 2024, esplicito=false, popolarita=91.5]

2) JSON compatto (e' quello che viaggia in rete):
   {"titolo":"Tuta gold","artista":"Mahmood","durataSecondi":188,"annoUscita":2024,"esplicito":false,"popolarita":91.5}

4) Oggetto ricostruito dal JSON ricevuto:
   Brano[30°C - ANNA, 2:27, 2024, esplicito=true, popolarita=89.0]

6) JSON incompleto / con campi extra:
   Brano[Espresso - Sabrina Carpenter, 0:00, 0, esplicito=false, popolarita=0.0]
